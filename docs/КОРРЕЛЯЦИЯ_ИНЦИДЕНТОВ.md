# Корреляция инцидентов

XFI Guard объединяет связанные события через граф зависимостей.

Пример:

```text
Exit-01 🔴
  ↑
  ├── Entry-01 🟡
  └── Entry-03 🟡
```

Вместо трёх независимых аварий создаётся один связанный инцидент:

**Корневая неисправность: Exit-01**

Затронуты: Entry-01, Entry-03.

Коррелятор не выполняет команды, не перезапускает службы и не изменяет конфигурацию. Его задача — только определить первопричину и передать результат следующему слою AI/Policy Engine.
