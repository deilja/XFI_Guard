# Мониторинг состояния и инциденты

Health Monitor получает безопасные снимки Discovery и сравнивает их с предыдущим состоянием.

## Правила

- первый снимок не создаёт ложный инцидент;
- потеря AWG после подтверждённого соединения создаёт инцидент высокого уровня;
- потеря выхода в Интернет создаёт инцидент высокого уровня;
- переход контролируемой службы из «работает» в «остановлен» создаёт инцидент;
- мониторинг не выполняет shell-команды и не изменяет сервер;
- время инцидента хранится в UTC.

## Следующий слой

Инциденты передаются в Dependency Graph. Если одновременно недоступны Exit и зависимые Entry, граф определяет первопричину, чтобы не создавать несколько независимых аварий.
