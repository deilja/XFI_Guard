# Регистрация доверенных узлов XFI Guard

Веб-интерфейс: **Серверы → Доверие**

Состояния узла:
- `Ожидает подтверждения`
- `Активен`
- `Отозван`
- `Истёк`

При регистрации узел передаёт только публичную часть сертификата и его
отпечаток. Закрытый ключ остаётся на самом узле и в XFI Guard не загружается.

Рекомендуемый срок сертификата: 90 дней.

Порядок:

1. Узел создаёт ключ и CSR локально.
2. XFI Guard получает CSR/публичный сертификат.
3. Администратор проверяет имя, роль и отпечаток.
4. Администратор нажимает **«Подтвердить узел»**.
5. Только после этого узел получает статус `Активен`.
6. При компрометации нажимается **«Отозвать»**.

Публичный management-доступ не включается автоматически.
