# AI-анализ инцидентов

AI Analyzer получает уже коррелированный инцидент и формирует русскоязычное объяснение:

1. краткое описание;
2. уровень риска;
3. вероятная первопричина;
4. диагностические проверки;
5. обратимый план восстановления.

## Безопасность

AI Analyzer не выполняет shell-команды, не перезапускает службы и не изменяет конфигурацию. Любое исправление требует отдельного слоя Policy/Approval.

Особенно защищены живые клиенты 3x-ui: inbound, пользователи, подписки и узлы нельзя удалять автоматически.

Текущая реализация содержит детерминированный fallback-анализатор. Подключение Groq/OpenAI выполняется следующим слоем через отдельный провайдер, без передачи секретов и без права исполнения.
