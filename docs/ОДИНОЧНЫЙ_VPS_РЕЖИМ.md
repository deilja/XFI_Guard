# XFI Guard — режим одного VPS

XFI Guard работает как **локальный агент безопасности для того VPS, на котором он установлен**.

- мониторинг выполняется локально;
- SSH/Fail2Ban/UFW/Xray/3X-UI проверяются локально;
- блокировка IP выполняется только локальным UFW/Fail2Ban;
- Telegram управляет только текущим экземпляром XFI Guard;
- подключение, регистрация и управление другими VPS не поддерживаются.

Многосерверные/cluster-компоненты удалены из стандартного deployment path.
