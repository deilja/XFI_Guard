# Telegram Remediation UI

Telegram показывает администратору AI-предложение без выполнения действия.

## Кнопки

- **Подтвердить** — только инициирует approval flow; executor должен отдельно проверить approval token.
- **Отклонить** — закрывает предложение без изменений.
- **Детали** — показывает сведения плана.
- **Отмена** — отменяет текущий UI flow.

Callback содержит только `plan_id`. В callback нельзя передавать shell-команды, секреты или произвольные параметры.

Перед исполнением workflow обязан:

1. загрузить точный план по `plan_id`;
2. проверить Telegram admin ID;
3. проверить HMAC approval token;
4. проверить TTL;
5. проверить fingerprint плана;
6. выполнить только разрешённое действие;
7. выполнить verify;
8. при необходимости выполнить rollback.
